# Лабораторна робота №2: Наука про дані: підготовчий етап

## Опис завдання
Робота складається з двох частин:
1. Автоматизоване завантаження, очищення та аналіз VHI-індексів з сервера NOAA.
2. Аналіз датасету `Individual Household Electric Power Consumption`: фільтрація, профілювання часу (timeit), нормалізація, стандартизація, кореляція та One-Hot Encoding.
