# Лабораторна робота №6: Обробка відео з камери (C++ & OpenCV)

## Вимоги
* **ОС:** Linux (Debian/Ubuntu) для коректної роботи `preinstall.sh`.
* **Залізо:** Наявність веб-камери.
* **ПЗ:** C++17, CMake, Make, OpenCV 4.x.

## Інструкція зі збірки та запуску
1. `./preinstall.sh`
2. `./build.sh`
3. `./run.sh`

## Керування
* Клавіші 0-3 - зміна режимів (Normal, Grayscale, Edges, Blur).
* Лівий клік мишею - малювання червоного кола.
* ESC або Q - вихід.
