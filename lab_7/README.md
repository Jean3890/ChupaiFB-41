# Лабораторна робота №7: Computer Vision та багатопотоковість у C++ (Рівень 2)

## Мета роботи
Навчитися поєднувати класичне програмування на C++ із сучасним CV/ML. Освоїти роботу з cv::dnn (Deep Neural Networks) для детекції об'єктів. Зрозуміти проблему блокування інтерфейсу важкими обчисленнями та вирішити її за допомогою std::thread та std::mutex, або std::condition_variable.

## Інструкція зі збірки
1. Виконайте `./preinstall.sh` для встановлення OpenCV та завантаження моделі (deploy.prototxt та .caffemodel).
2. Виконайте `./build.sh` для компіляції за допомогою CMake.
3. Запустіть програму скриптом `./run.sh`.

## Архітектура програми
Програма побудована за модульним принципом з використанням багатопотоковості для уникнення блокування UI-потоку:

* **Клас `FaceDetector`:** Відповідає за інференс нейромережі. Він запускає окремий фоновий потік (`std::thread workerThread`).
* **Main Thread (UI):** Постійно читає кадри з вебкамери з максимальною частотою (30+ FPS), віддає копії кадрів детектору та відображає відео.
* **Синхронізація:** Обмін кадрами та координатами обличчя між потоками відбувається із використанням `std::mutex` (`std::lock_guard`), що унеможливлює стан гонитви (race conditions). Для безпечної зупинки потоку використовується прапорець `std::atomic<bool> isRunning`.

*Примітка: У метод `workerLoop` додано штучну затримку 500 мс для явної демонстрації того, що UI-потік працює незалежно і відео залишається плавним.*
