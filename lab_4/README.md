# Лабораторна робота №4: Візуалізація даних 2 

## Опис завдання
У цій роботі реалізовано програму з графічним інтерфейсом користувача (GUI) для візуалізації гармонічної функції з накладеним шумом. Програма дозволяє інтерактивно змінювати параметри сигналу та шуму, а також застосовувати низькочастотний IIR-фільтр (Баттерворта) для очищення сигналу від шуму.

## Інструкція для користувача
1. Запустіть скрипт `lab4.py` у вашому Python-середовищі. Відкриється нове вікно з інтерактивним графіком.
2. **Керування сигналом:** Використовуйте верхні три повзунки (`Амплітуда`, `Частота`, `Фаза`) для зміни форми базової гармоніки.
3. **Керування шумом:** Використовуйте нижні два повзунки для зміни параметрів накладеного шуму: 
   - `Mean` зсуває шум по вертикалі.
   - `Var` (дисперсія) змінює інтенсивність/розкид шуму.
4. **Порівняння ліній:** Використовуйте чекбокси зліва внизу, щоб вмикати/вимикати відображення чистої гармоніки, зашумленого сигналу або результату фільтрації.
5. **Скидання:** Для повернення всіх повзунків до початкового стану натисніть кнопку `Reset` справа внизу.
