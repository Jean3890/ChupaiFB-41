# Лабораторна робота №3: Візуалізація даних


## Опис завдання
У цій роботі проводиться очищення та аналіз датасету **Census Income (Adult)** з репозиторію UCI. 
Мета роботи — знаходження інсайтів та побудова багатовимірних візуалізацій (lineplot, scatterplot, boxplot, heatmap та гістограм), що показують залежність між демографічними даними, робочими годинами та рівнем доходу (більше чи менше $50K).

## Інструкція із запуску
1. Переконайтеся, що у вас встановлено Python (рекомендовано 3.10+).
2. Створіть та активуйте віртуальне середовище:
   `python -m venv .venv`
   `.\.venv\Scripts\activate` (для Windows)
3. Встановіть необхідні залежності:
   `pip install -r requirements.txt`
4. Відкрийте файл `.ipynb` у Jupyter Notebook або VS Code та запустіть комірки послідовно. Дані завантажуються автоматично за прямим посиланням.
